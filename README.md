## 📖 **Tentang Proyek**

**Berpikir Komputasional** adalah modul pembelajaran interaktif berbasis web yang dirancang khusus untuk siswa **SMA Kelas XI**. Modul ini mengintegrasikan konsep fundamental Computational Thinking dengan visualisasi interaktif, simulasi algoritma, dan sistem evaluasi yang komprehensif.

Dikembangkan oleh **Ramdan Ahmad Dijaya, S.Pd.** — Guru Informatika di SMA Islam Al-Mizan Jatiwangi, modul ini bertujuan untuk membekali siswa dengan kemampuan berpikir komputasional yang esensial di era digital.

### 🎯 **Tujuan Pembelajaran**

Setelah menyelesaikan modul ini, siswa diharapkan mampu:

## ✨ **Fitur Utama**

### 🎨 **Visualisasi Struktur Data LIVE**

| Fitur | Deskripsi |
|-------|-----------|
| **📚 Stack Visualizer** | Push/Pop dengan animasi real-time, tampilan LIFO |
| **🚶 Queue Visualizer** | Enqueue/Dequeue interaktif, tampilan FIFO |
| **🌳 Tree Builder** | Tambah node dinamis dengan visualisasi hierarki |
| **🔗 Graph Builder** | Tambah node dengan visualisasi jaringan |

### 🧪 **Simulator Algoritma**

| Fitur | Deskripsi |
|-------|-----------|
| **💰 Coin Problem** | Perbandingan Brute Force vs Greedy |
| **🔎 Binary Search** | Step-by-step visualization Divide & Conquer |

### 🧠 **Decision Maker**

- 5 skenario pemilihan struktur data dan algoritma
- Feedback interaktif untuk setiap pilihan
- Pembelajaran berbasis kasus

### 📝 **Quiz & Assessment**

- 15 soal pilihan ganda
- Penilaian otomatis dengan skor persentase
- **Sertifikat Kelulusan** (nilai > 80) dengan fitur cetak

### 📁 **Proyek Mini**

- Studi kasus: Sistem Manajemen Perpustakaan Al-Mizan
- Simulasi pemilihan teknologi yang tepat
